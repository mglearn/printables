Texas Grab-and-Go Substitute Packets

Print-and-go substitute lessons a teacher can pick, print, and leave — a full class period with no prep, no logins, no internet, and ordinary classroom materials. Each packet has a substitute guide, a student packet, and a separate answer key. Grades 6–8 pilot across Reading, Math, Science, and Social Studies.

In development. This collection is being built one vertical slice at a time, starting with Grade 7 Science. Standards references are provisional and pending educator verification against the current official Texas Administrative Code — packets do not claim formal alignment until reviewed.

How each packet works

Every packet follows the same routine so students recognize it even when the subject changes: Start → Build → Apply → Explain → ACE close → (optional) Continue. The substitute guide is readable in five minutes and needs no subject expertise; the answer key is always a separate file so it is never copied for students. Everything prints clearly in grayscale and reflows as accessible HTML.
