Comparing & Ordering Numbers

Use the cue, then fade the cue. Study the cue card for 60 seconds. Then cover it before answering Round 1. Check the card only after you commit to an answer.

Cue focus  Line up the place values and compare from the left. The first place where the digits are different tells you which number is bigger. Use > (greater than), < (less than), or = (equal). To order numbers least to greatest, compare them in pairs. Example: 4,512 and 4,521 match until the tens place (1 vs 2), so 4,512 < 4,521.

Round 1 — Retrieve It

  1. When comparing numbers, do you compare from the left or the right?
  2. What does the symbol > mean?
  3. Compare using >, <, or =: 4,512 ___ 4,521.
  4. What should you do first before you compare two numbers?

Round 2 — Sketch It

Line up 4,512 and 4,521 in a place-value chart, one above the other. Circle the first place where the digits are different.

Comparing & Ordering Numbers — Apply It

Keep the cue card covered. Answer first. Then use the cue to check, revise, and explain what you changed.

Round 3 — Apply the Idea

  1. Compare using >, <, or =: 3,089 ___ 3,098. Which place decided it?
  2. Order these least to greatest: 615, 651, 561.
  3. Compare using >, <, or =: 0.7 ___ 0.70. Explain.

Round 4 — Reason from Evidence

Ana says 4,512 is greater than 4,521 because 12 is more than 21 backwards. Is she correct? Line up the place values and explain the right comparison.

Comparing & Ordering Numbers — ACE It

Use the cue card only if you need it. The goal is to show what you can explain, connect, and use on your own.

A

Articulate

Explain how to compare two multi-digit numbers. Use the words line up, place value, and from the left.

C

Connect

Connect comparing numbers to a real choice, such as picking the higher score in a game or the lower price. Give one example.

E

Extend

Write three different 4-digit numbers, then order them from greatest to least. Show one comparison with a symbol.

Confidence check. Circle one after you finish: I still need the cue / I need it once in a while / I can explain this without it.

Teacher Key — Comparing & Ordering Numbers

Remove this page before student copying. Answers below give expected ideas, not required wording.

Retrieve It

  1. From the left.
  2. Greater than (the number on the left is larger).
  3. 4,512 < 4,521.
  4. Line up the place values (same places under each other).

Sketch It — look for

Both numbers lined up by place. Thousands (4=4) and hundreds (5=5) match; the tens place (1 vs 2) is circled as the first difference.

Apply It

  1. 3,089 < 3,098. The tens place (8 vs 9) decided it.
  2. 561, 615, 651.
  3. 0.7 = 0.70. They name the same amount; the extra 0 in the hundredths place adds nothing.

Reason from Evidence — look for

No. Lining up place values, both start 4,5__; the tens place is 1 vs 2, so 4,512 < 4,521. You compare places from the left, not read the digits backward.

ACE — Extend look-for

Three distinct 4-digit numbers ordered greatest to least, with at least one correct > or < statement between two of them.

Suggested use. Run Page 1 with the cue card available, Page 2 with the cue mostly covered, and Page 3 as independent reflection. Let students uncover the cue to self-correct in a different color.
